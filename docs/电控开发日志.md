# CRTC2026 电控开发日志

## 1. 开发环境搭建与工具链选型
**日期**：2026年9月21日

**功能描述**：搭建 STM32F103C8T6 的编译、烧录与调试环境。

**开发历程**：
- **工具选型**：对比了 VS Code、Visual Studio 和 STM32 官方工具。考虑到零基础入门，最终选择 `STM32CubeIDE + STM32CubeMX` 的组合。CubeMX 用于图形化配置底层引脚和时钟，CubeIDE 用于编写业务逻辑和编译烧录，这套方案能极大降低底层寄存器配置的出错率。
- **环境踩坑**：安装 CubeIDE 汉化包后，Information Center 报错 `ClassCastException`。排查后发现是汉化包与 Eclipse 底层组件冲突。为了保证开发环境绝对稳定，放弃汉化，直接使用英文原版界面，编译和烧录功能不受影响。
- **工作流确立**：明确了“CubeMX 配底层 -> 生成代码 -> CubeIDE 写 USER CODE 区”的标准流程，确保后续迭代时代码不会丢失。


## 2. 时钟树配置与验证
**日期**：2026年9月21日

**功能描述**：配置系统时钟，使 STM32F103C8T6 运行在最高性能状态（72MHz）。

**开发历程**：
- **时钟源选型**：芯片支持内部 RC 振荡器（HSI，8MHz）和外部晶振（HSE，8MHz）两种时钟源。查阅数据手册后发现，内部 HSI 精度较差（受温度和电压影响会漂移），且作为 PLL 输入时最高只能到 64MHz，无法稳定达到 72MHz。外部晶振精度高、频率稳定，可以可靠倍频至 72MHz。因此选择 HSE 作为时钟源。
- **配置过程**：在 CubeMX 的 Clock Configuration 中，直接填写 HCLK=72MHz，CubeMX 自动将 PLL 倍频设为 ×9，AHB 分频 /1，APB1 分频 /2，APB2 分频 /1。
- **安全性验证**：针对自动生成的连带改动，对照数据手册进行了安全性验证。确认 APB1 实际频率为 36MHz（符合 36MHz 上限规定），APB2 实际频率为 72MHz，各项参数均在 STM32F103 规范内，无超频或违规风险，可安全使用。


## 3. GPIO 点灯测试（底层链路验证）
**日期**：2026年9月22日

**功能描述**：控制板载 LED（PC13）闪烁，验证编译与烧录链路是否通畅。

**开发历程**：
- **引脚选择**：查阅 DS5319 数据手册 Table 5，选择 PC13 作为输出引脚（该引脚核心板默认接了 LED）。
- **注意事项**：查阅手册发现，PC13 属于备份域供电，最大输出电流仅有 3mA（普通引脚为 20mA），不能用于驱动大负载，仅适合点灯。
- **代码实现**：在 CubeIDE 的 `main.c` 中，严格在 `/* USER CODE BEGIN 3 */` 安全区内写入 `HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13)` 和 `HAL_Delay(500)`。
- **资源评估**：编译通过，生成 `.elf` 文件。终端显示 Flash 占用 4.7KB，RAM 占用 1.5KB。极低的资源占用为后续添加电机、PS2、舵机代码留出了极其充足的 64KB 空间。


## 4. 代码生成与编写逻辑
**日期**：2026年9月23日

**功能描述**：确定工程的代码生成与编写方式。

**设计思路**：
- 底层初始化代码（时钟、GPIO等）由 CubeMX 自动生成，业务逻辑在 `USER CODE` 区域手动编写。
- 底层配置不手动修改，统一通过 CubeMX 图形界面调整，重新生成后自动更新。
- 后续业务代码按模块封装为独立函数，在主循环中调用。


## 5. 硬件连接与首次烧录（点灯成功）
**日期**：2026年9月24日

**功能描述**：连接 ST-Link 与 STM32 核心板，完成首次烧录，实现板载 LED 闪烁。

**开发历程**：
- **硬件到货与检查**：收到 ST-Link V2 仿真器与 STM32F103C8T6 核心板。确认 ST-Link 接口为 Mini-USB，核心板排针焊接完好。
- **驱动确认**：将 ST-Link 插入电脑，设备管理器“通用串行总线设备”中识别到 `STM32 STLink`，确认 CubeIDE 安装时已自动完成驱动部署，无需手动安装 STSW-LINK009。
- **接线方案**：采用 SWD 模式，仅需 4 根杜邦线。对应关系为：ST-Link 的 `3.3V`→核心板 `3.3V`、`GND`→`GND`、`SWDIO`→`SWIO`（核心板丝印简写）、`SWCLK`→`SWCLK`。接线时确保杜邦线插紧，避免接触不良。
- **烧录过程**：打开 CubeIDE 的 `crtc_led` 工程，点击 Run 进行烧录。过程中弹出 ST-Link 固件升级提示（显示固件版本 Unknown），因使用的是兼容版 ST-Link，选择关闭该窗口不进行升级，避免变砖风险。
- **点灯结果**：烧录完成后，控制台显示烧录成功、无错误。核心板上的 PC13 LED 以 1Hz 频率闪烁（每 500ms 翻转一次，亮灭各 500ms），首次硬件链路验证通过。

**经验总结**：硬件链路已打通，软件环境与驱动均正常。核心板上的 `SWIO` 即 `SWDIO` 的简写，两者功能一致。兼容版 ST-Link 遇到固件升级提示时，在不影响烧录的前提下应优先选择跳过。
